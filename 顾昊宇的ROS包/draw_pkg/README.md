# Draw Face (ROS Node) - 实时情感驱动表情生成ROS包

📋 **概述**
`draw_pkg` 是一个基于ROS（机器人操作系统）的实时表情生成包。它订阅情感话题，接收用户的情感概率和标签，通过VAD（效度、唤醒度、优势度）情感模型和扩散模型，将情感数据转化为几何参数，最终绘制出1024×1024的灰度表情图像。本包是`draw_a_face_old`的升级版，移除了手动输入，改为ROS话题驱动，并优化了路径独立性，可在任何目录下通过`rosrun`正常运行。

**核心目标**：根据实时感知的用户情感，生成恰当的表情以促进用户的愉悦体验。

第二部分————怎么使用这个包里的内容？
🚀 一、快速启动

bash
# 在ROS环境下运行（确保roscore已启动）
rosrun draw_pkg draw.py
该节点启动后，会显示一个OpenCV窗口“Machine Expression”，并订阅以下话题：

/emotion_label (std_msgs/String)：当前主导情感标签

/emotion_probs (std_msgs/Float32MultiArray)：7类情感概率数组

当收到新消息时，节点自动生成并更新表情。

📡 二、数据交互流程

text
test.py（或其他发布者）
   ↓ 发布 /emotion_label + /emotion_probs
draw.py（订阅者）
   ↓ 回调缓存数据
   ↓ 调用 new_usage(probs, label)  →  (D, 5维向量)
   ↓ 计算 k = D * golden_ratio
   ↓ 使用几何数据绘制图像
   ↓ 更新窗口显示
🔄 三、数据处理流程

输入：从话题接收的7类概率数组和情感标签。

转换：new_usage内部调用扩散模型，将前两个概率加权值（V,A）作为条件，生成5维抛物线参数；同时返回第三维D。

参数融合：D乘以黄金比例得到眉毛斜率k。

绘图：结合预加载的圆环、椭圆点，以及动态计算的眉毛和嘴巴区域，生成完整表情。

输出：实时显示在窗口中，也可按s键保存当前图像到results/目录。

💾 四、输出结果

实时窗口：1024×1024灰度表情图，缩放至512×512显示。

保存图像：按s键保存为expression_时间戳.png到当前工作目录（如需固定路径可修改代码）。

第三部分————这个包是如何把输入的情感数据变成一整个表情图像的？原理是什么？
🧠 一、情感-几何映射流程

text
情感概率 + 标签
    ↓ (emotion_to_expression_params)
new_usage()  →  (D, 5维向量)
    ↓
几何参数：
  - k = D × golden_ratio（眉毛斜率）
  - parabola: [curve1, height1, curve2, height2, x_max]（嘴巴形状）
    ↓
绘图模块：
  - 圆环（base.npy）
  - 椭圆（ellipses.npy）
  - 线段带（由k控制）
  - 抛物线区域（由5个参数控制）
    ↓
表情图像
🔄 二、扩散模型 (translation.py)

基于Denoising Diffusion Probabilistic Model (DDPM)的轻量级实现，负责将条件向量（V,A）映射为5维几何参数。核心函数为new_usage，它整合了归一化、模型推理和反归一化。

输入：7类概率数组 + 可选标签

输出：(D, 5维向量)，其中D为VAD的第三维，5维向量用于抛物线参数。

📐 三、几何绘图 (draw.py)

使用四种几何元素构建表情：

圆环：预生成的脸型轮廓（base.npy）

椭圆：预生成的眼睛特征（ellipses.npy）

线段带：动态生成的眉毛，由k控制倾斜度（k = D * golden_ratio）

抛物线区域：动态生成的嘴巴，由curve1, height1, curve2, height2, x_max决定形状

第四部分————“效度”、“唤醒度”和“优势度”都是什么东西？
（此部分内容与旧版基本一致，保留作为背景知识）

🎭 VAD各维度的决定因素

效价 (Valence) - 愉悦程度
机器的愉悦基调是为引导用户情绪而选择的表达策略，主要取决于用户当前的情绪水平及“情绪差距”。

唤醒度 (Arousal) - 能量或活跃程度
旨在调节互动节奏与用户注意力，通常适度匹配并略高于用户的活力状态。

优势度 (Dominance) - 主导性或引导力度
反映机器在互动中承担引导角色的程度，根据用户对引导的需求动态调整。

本包中，V/A用于生成嘴巴形状，D直接控制眉毛斜率，从而实现情感维度的解耦表达。

第五部分————如何为机器选择V、A、D值？
虽然本包不再手动输入VAD，但理解如何取值有助于调试或设计发布节点。

🎯 常用情感组合示例

对方当前状态	建议机器表情	VAD值示例	表情特征
对方悲伤	温暖鼓励	(0.8, 0.6, 0.3)	温暖微笑，略带鼓励
对方愤怒	平静理解	(0.4, 0.2, -0.2)	平静表情，略带谦逊
对方焦虑	稳定安抚	(0.6, 0.1, 0.4)	稳定微笑，适度自信
对方冷漠	热情友好	(0.7, 0.5, 0.2)	热情友好，适度活跃
⚠️ 危险组合警告
避免以下不自然的组合：

(-1.0, 1.0, 1.0) → 威胁性愤怒

(1.0, -1.0, -1.0) → 矛盾表情（快乐但无力）

(0.0, 0.0, 0.0) → 过度中性，显得冷漠

实时视频流：优化生成速度以支持连续视频帧（>10Hz）。

参数动态平滑：增加插值机制，避免表情突变。

第七部分————其他可能存在的问题
❓ 常见问题

Q: 为什么表情生成有延迟？
A: 扩散模型推理耗时（约1-3秒），后续版本将尝试优化。

Q: 如何修改输出图像大小？
A: 需修改draw.py中的图像尺寸常量（1024），并重新生成基础几何点文件（base.npy、ellipses.npy）。

Q: 可以生成彩色图像吗？
A: 当前为灰度图，可扩展绘图函数添加颜色参数。

Q: 如何在没有ROS的环境下测试？
A: 可临时注释ROS相关代码，直接调用emotion_to_expression_params并传入模拟概率进行测试。

Q: 为什么k值要乘以黄金比例？
A: 黄金比例（约0.618）是美学上的理想比例，使眉毛倾斜度更符合人类审美。

Q: 为什么需要临时切换工作目录？
A: 因为translation.py内部使用相对路径加载base/extra.npy和train/train_all.pth，切换目录确保文件能被找到。未来可改为绝对路径消除此依赖。
